Scope: `src/Volt.Cli`, `src/Volt.Ide.Codesys`, `src/Volt.Ide.Twincat` (+ `.Explorer`), the connector (`Volt.Connector`, `Volt.Connector.Core`), `Volt.Relay`, `Volt.Wire`, `Volt.Engine.Host`, `Volt.Contracts`, `scripts/`, `test/` structure.
Skipped: `Format/Network`, `CodesysNetwork{Reader,Writer}.cs`, `TcNetwork{Reader,Writer}.cs` (being rewritten elsewhere). No DIALECT.md asymmetry is proposed for unification.
Read-only: nothing was edited, staged or committed. Every "0 callers" claim was checked by grepping `src`, `test`, `scripts` (incl. the IronPython that reaches the CODESYS DLL: only `PipeHost.Start/Stop`, `NwlInterop.New`, `CodesysNetworkReader.ReadNetwork`).

Sorting: sections A (bridges/CLI/tests) and E (connector & friends) is behaviour-neutral (lines removed × safety, high first); section B removes code but changes behaviour on an already-broken path (silent fallback → loud failure) — each needs a red test first and the owner's nod; section C is comment/doc-only.
