Network text

The text form of an LD or FBD body: the vendor's network model (NWL) written one to one. Each item is its tree, root first, ending with ;. A box is its name; :=, S= and R= are coils. Writer, reader and validator are NetworkTextWriter, NetworkTextReader and NetworkValidator in Volt.Engine/Format/Network/; the LSP ports the reader and the validator. 

%LANGUAGE LD
NETWORK TITLE: "Start the motor"
  // runs while auto is on
  split1 := start AND NOT stop;
  motor := lamp := split1;
  ready := MOVE 100 => speed ENO EN split1;
  alarm := a BRANCH (b, c AND d);
END_NETWORK

Grammar

body      = "%LANGUAGE" , ( "LD" | "FBD" ) , NL , { network } ;
network   = header , NL , { comment } , ( unsupported | { item } ) , "END_NETWORK" ;
header    = "NETWORK" , [ "LABEL:" , name ] , [ "DISABLED" ] , [ "TITLE:" , string ] ;
comment   = "//" , [ " " , text ] , NL ;
unsupported = "UNSUPPORTED" , string , "#" , hex8 , ";" ;
item      = [ top ] , ";" ;
top       = assign | split | slot ;
assign    = coil , { coil } , slot ;
coil      = [ edge ] , ( [ "NOT" ] , head , ":=" | head , ( "S=" | "R=" ) ) ;
head      = target | "JMP" , name | "RETURN" ;
split     = splitname , ":=" , slot ;
slot      = box | parallel | term | "(" , ( assign | split ) , ")" ;
term      = [ mods ] , ( atom | call ) | mods , "(" , box , ")" | splitname | "NOT" | (* empty *) ;
operand   = term | "(" , ( box | parallel | assign | split ) , ")" ;
box       = ( wordbox | movebox | call | execute ) , pinstate ;
wordbox   = operand , word , operand , { word , operand } , { "=>" , target } ;
movebox   = "MOVE" , operand , { "=>" , target } ;
call      = [ name , ":" ] , ( target | "`" , word , "`" ) , "(" , [ pin , { "," , pin } ] , ")" , [ "." , name ] ;
pin       = [ mods ] , name , ":=" , slot | name , "=>" , target | "=>" , [ target ] | operand ;
execute   = "EXECUTE" , NL , { st-line , NL } , "END_EXECUTE" ;
pinstate  = [ "ENO" , [ "=>" , target ] ] , [ [ mods ] , "EN" , slot ] ;
parallel  = [ operand ] , "BRANCH" , "(" , slot , "," , slot , { "," , slot } , ")" , [ "SHORTCIRCUIT" ] ;
mods      = edge , [ "NOT" ] | "NOT" ;
edge      = "R_EDGE" | "F_EDGE" ;
target    = token | backtick ;
splitname = "split" , digits ;
word      = "AND" | "OR" | "XOR" | "ADD" | "SUB" | "MUL" | "DIV" | "MOD" | "GT" | "GE" | "EQ" | "NE" | "LE" | "LT" ;

Whitespace and newlines are layout, except in the header line, a // line and an EXECUTE body. A continuation line of an item is indented deeper than the item's first line. Words are case-insensitive. Reserved: EN ENO BRANCH SHORTCIRCUIT JMP RETURN EXECUTE END_EXECUTE NOT R_EDGE F_EDGE NETWORK END_NETWORK UNSUPPORTED MOVE, the words and split<n>; a name spelled like one is backticked.

How a box is read

lamp := MOVE 1 => t ENO EN c;          // through its ENO: it shows ENO
sum := a ADD b EN c;                    // by its value
x := t1 : TON(IN := a, PT := T#1S).Q;   // an FB by its .name
ready := v1 : Valve(open := on);        // an FB that declares ENO, by it
ok := f(IN := a) ENO;                   // a function through its ENO, without EN

ENO shows the box's ENO pin and comes after its outputs; EN comes last. An operator shows ENO only with EN. A box in the EN slot of another runs first; the writer lays such a chain out as a staircase: 

lamp := MOVE 3 => c ENO EN
          MOVE 2 => b ENO EN
            MOVE 1 => a ENO EN start;

A network that cannot be spelled

NETWORK TITLE: "Calc"
  UNSUPPORTED "a flag on a box input pin" #3f9a01c2;
END_NETWORK

Pull never fails: the network keeps its header and comment and shows this one line, with the stored network's hash. Pushed back unchanged it is kept exactly as the IDE holds it; edited, it is refused.

The body line

METHOD Run : BOOL
VAR_INPUT
    a : BOOL;
END_VAR
%LANGUAGE ST
Run := a;
END_METHOD

ACTION Step
%LANGUAGE SFC UNSUPPORTED
END_ACTION

The line ends the declaration and its language alone picks the reader: ST, LD or FBD. A body Volt does not show (CFC, SFC, IL) is its language and UNSUPPORTED, with nothing under it: the declaration stays editable and a push never writes the body. A member whose IDE object has no body slot has no line.

Pushing

A push pairs networks by their text (NetworkPairing). An equal network is not touched; a changed one is rebuilt; inserts and deletes touch no other network. Members the text does not carry are derived from the declarations (a callee's pin names, an FB output's slot) or kept from the stored network; a rebuild that drops a stored value is named (RebuildLoss). Any layout the reader accepts is pushed; the next pull shows the writer's.

Errors

coderaised for
NETWORK_PARSEStructure: a missing ;, header fields out of order, a // after an item, an unclosed backtick, string or EXECUTE body, a bad escape, .ENO.
NETWORK_NOT_CLOSEDA NETWORK with no END_NETWORK.
NETWORK_DUPLICATE_NAMEA split defined twice in one network.
NETWORK_BAD_EXPRESSIONA text no tree prints: a redundant bracket, two words at one level, the call form where the word fits, ENO without EN, an FB call without its type, a split never defined.
NETWORK_UNKNOWN_OPERATORA symbol that is no word; ST's + - * / and comparisons name the word to write.
NETWORK_UNSUPPORTEDA tree the vendor does not store or build, or one not measured, named by its shape: x := MOVE 1 ENO EN c; ("an operator box read through its ENO with no output wired").

The language server and the case set

The LSP's reader (volt-lsp-iec/src/frontend/syntax/network/) gives the same error at the same token as the push, and hints that ENO => v never writes v. Both read test/fixtures/network-text/: accept/*.cases (a text and its model) and refuse/*.cases (a text and its error).
