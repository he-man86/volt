Network text

An LD or FBD body is ST: every box is a call, a contact is AND, OR or NOT between operands, a coil is an assignment. Lines starting with % carry what is not code. 

%LANGUAGE LD
%NETWORK "Start the motor"
VAR_TEMP w1 : ANY; END_VAR
// runs while auto is on
w1 := start AND NOT stop;
motor := w1;
lamp := MOVE(EN := w1, 100, OUT => speed).ENO;

Marks

A mark is written where the IDE stores it: on a value, or before the receiver it belongs to.

The same words mark EN (MOVE(NOT EN := c, 1, OUT => n)), an output (NOT Q => x) and a box read where it stands (y := NOT t1(IN := a).Q;). Two marks stack edge first: RISING NOT y := a;, RISING(NOT a).

In a chain every target receives the rung's power flow and applies its own mark, so a marked coil stands first: NOT y := x := a;.

EN, ENO and outputs

The call is the box. EN := written first shows EN; .ENO closes the call of a box showing ENO; .NAME names the output a box hands on where its callee declares more than one (OUT is a function's value). 

x    := GT(EN := c, a, b);
done := MOVE(EN := MOVE(EN := c, 1, OUT => x).ENO, 2, OUT => y).ENO;
y    := f(IN := a).ENO;
x    := AND(r1(CLK := a), b);
t    := t1(IN := a, PT := T#1S).ET;
q    := g(a, Q => v).OUT;
MOVE(EN := c, 7, ENO => lamp, OUT => x).ENO;

Wires

%NETWORK
VAR_TEMP w1 : ANY; w2 : ANY; END_VAR
w1 := a AND b;
w2 := t1(IN := w1).Q;
x := w2;
y := w2 AND w1;

A value read twice is a wire, declared : ANY on the network's one VAR_TEMP line (its type is its definition's) and defined once (w1 := …). A box read once stands where it is read.

Wires are numbered w1, w2, … across the body, in the order the text first names them, past every name the body or its declarations use; the VAR_TEMP line lists them in that order.

Execute box

Its ST is its last pin, one string, line breaks as they stand, ' written $' and $ written $$. Its one output is its ENO.

EXECUTE(EN := go, 'IF start THEN
    count := count + 1;
END_IF');
ok := EXECUTE(EN := go, 'msg := $'done$';');

What a network holds

Assignments (a jump or the return among their targets) and calls (a box at a root closed by .ENO or by nothing). Any other ST stands only in an Execute box. RISING, FALLING and RAIL name nothing else in a network.

A network that cannot be spelled

%NETWORK "Calc"
%UNSUPPORTED "a mark on a jump or a return" #929f3675

Pushed back unchanged it stays as the IDE holds it; edited, the push is refused.

Pushing

A push rebuilds only the networks whose text changed; what the text does not carry is derived from the declarations or kept from the stored network.
