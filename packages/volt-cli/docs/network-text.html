Network text

An LD or FBD body is ST: every box is a call, a contact is AND, OR or NOT between operands, a coil is an assignment. Lines starting with % carry what is not code. Writer and reader are StNetworkWriter and StNetworkReader in Volt.Engine/Format/Network/; the language server reads the body with its ST parser. 

%LANGUAGE LD
%NETWORK "Start the motor"
%WIRES w1
// runs while auto is on
w1 := start AND NOT stop;
motor := w1;
lamp := MOVE_EN(EN := w1, 100, OUT => speed);

EN and ENO

The suffix names the pins a box shows; the call returns what the suffix says.

suffixshowsreturnsexample
_ENEN, ENOENOlamp := MOVE_EN(EN := c, 1, OUT => x);
_ENOENOENOok := f_ENO(IN := a);
_ENONLYENthe valuex := GT_ENONLY(EN := c, i, 3);

A box read by its ENO hands its value on only through OUT =>. ENO wired beside the outputs:

MOVE_EN(EN := c, 7, ENO => lamp, OUT => x);

An FB called on its instance takes the suffix on the instance: t1_EN(EN := c, IN := a, Q => x);.

Wires

%NETWORK
%WIRES w1
w1 := a AND b;
x := w1;
y := w1 AND c;

A value read twice is a wire: named on the %WIRES line, defined once (w1 := … or Q => w1), read by name. A box read once stands where it is read. The writer names wires w1, w2, … across the body.

Execute box

%NETWORK
%EXECUTE(EN := go)
IF start THEN
    count := count + 1;
END_IF
%END_EXECUTE

What a network holds

A network holds assignments, calls, jumps and returns. No IF, CASE, loop or EXIT; no infix box (i + 1, a XOR b, i > 3 — write the call: ADD(i, 1)). ST of any kind stands only in an Execute box.

A network that cannot be spelled

%NETWORK "Calc"
%UNSUPPORTED "a coil modifier on a jump" #929f3675

A pull never fails: the network keeps its title and shows this line, with the stored network's hash. Pushed back unchanged it stays as the IDE holds it; edited, the push is refused.

The body line

METHOD Run : BOOL
%LANGUAGE ST
Run := a;
END_METHOD

ACTION Step
%LANGUAGE SFC UNSUPPORTED
END_ACTION

The line ends the declaration; its language picks the reader. CFC, SFC and IL are their language and UNSUPPORTED, with nothing under it: the declaration stays editable and a push never writes the body.

Pushing

A push pairs networks by their text (NetworkPairing): an equal network is not touched, a changed one is rebuilt. What the text does not carry is derived from the declarations or kept from the stored network; a rebuild that drops a stored value is named (RebuildLoss). Any layout the reader accepts is pushed; the next pull shows the writer's.
