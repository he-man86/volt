Network text

The text form of an LD or FBD body: the vendor's network model (NWL), written the way the drawing reads. A box is its name; :=, S= and R= are coils; one ; ends one NWL item; the only named thing is a split point. Writer, reader and push gate are NetworkTextWriter, NetworkTextReader and NetworkTextGate in Volt.Engine/Format/Network/; the LSP ports the reader. 

IMPLEMENTATION LD
NETWORK TITLE: "Start the motor"
  split1 := start AND NOT stop;
  motor := lamp := split1;
  MOVE 100 => speed EN split1
  ready := ENO;
  alarm := a BRANCH (b, c AND d);
END_NETWORK

The rules

ruleexample
P1 wordsEN ENO BRANCH SHORTCIRCUIT JMP RETURN EXECUTE END_EXECUTE NOT R_EDGE F_EDGE NETWORK END_NETWORK UNSUPPORTED, the box words and split<n>. A name spelled like one is backticked: y := `ENO`;
P2 linesOutside brackets a line break ends the line, unless the line ends with an infix word, BRANCH, =>, :=, S= or R=. Inside brackets it is layout.
P3 open linesA line without ; is open. Each ENO takes the oldest open line above it not yet taken; every open line is taken once.
P4 bracketsA slot holds one box. Brackets mark only: a word box or parallel as another word's operand, an enabled comparison used as a value, a nested assignment.
P5 word or callA box is its word when every input is a plain positional value with the default formals; otherwise the call form WORD(…).
P6 parallel[feed] BRANCH (b1, b2, …) [SHORTCIRCUIT]
P7 jumpsJMP l and RETURN are coils: JMP l := c;, alone on the rail JMP l;
P8 EXECUTEEXECUTE [EN [c]], the raw ST lines, END_EXECUTE
P9 splitssplit<VarId>, defined once per network with :=, referenced anywhere in it
P10 headerNETWORK [LABEL: x] [DISABLED] [TITLE: "…"], then // comment lines
P11 body membersDerived on push; never written in the text
P12 literalsBare: -1, 'text', T#1S
P13 LSPEvery push refusal is also an error while typing

Grammar

body        = "IMPLEMENTATION" , ( "FBD" | "LD" ) , NL , { network } ;
network     = header , NL , { comment } , ( unsupported | { item } ) , "END_NETWORK" ;
header      = "NETWORK" , [ "LABEL:" , name ] , [ "DISABLED" ] , [ "TITLE:" , title ] ;
unsupported = "UNSUPPORTED" , '"' , phrase , '"' , ";" ;
comment     = "//" , [ " " ] , { char - NL } , NL ;

item        = { open } , statement , ";" ;                          (* one per NWL item *)
open        = root , NL ;                                           (* its ENO is read below *)
statement   = assign | split | jump | root | (* empty *) ;
assign      = coil , { coil } , ( value | "NOT" ) ;
coil        = target , op | modifier , target , ":=" | ( "JMP" , name | "RETURN" ) , ( ":=" | "S=" ) ;
modifier    = "NOT" | "R_EDGE" | "F_EDGE" ;
op          = ":=" | "S=" | "R=" ;
split       = "split" , digits , ":=" , value ;
jump        = "JMP" , name | "RETURN" ;
root        = level , [ [ "NOT" ] , "EN" , [ value ] ] | execute ;

value       = [ level ] ;
level       = word-box | parallel | operand-or-call ;
word-box    = operand , word , operand , { word , operand } , { "=>" , target }
            | "MOVE" , operand , { "=>" , target } ;
parallel    = [ feed ] , "BRANCH" , "(" , [ value ] , "," , [ value ] , { "," , [ value ] } , ")" , [ "SHORTCIRCUIT" ] ;
operand     = [ "NOT" ] , ( atom | "(" , bracketed , ")" ) | edge ;
bracketed   = word-box | parallel | level , "EN" , [ value ] | assign | split ;
edge        = ( "R_EDGE" | "F_EDGE" ) , "(" , [ "NOT" ] , value , ")" ;
atom        = token | backtick | "ENO" | "split" , digits | call ;
call        = ( "???" , ":" , name | head ) , "(" , [ pin , { "," , pin } ] , ")" , [ "." , name ] ;
pin         = [ [ modifier ] , name , ":=" ] , value | name , "=>" , target | "=>" , [ target ] ;
execute     = "EXECUTE" , [ "EN" , [ value ] ] , NL , st-lines , "END_EXECUTE" ;
target      = token | backtick ;
backtick    = "`" , { char - "`" } , "`" ;
word        = "AND" | "OR" | "XOR" | "ADD" | "SUB" | "MUL" | "DIV" | "MOD"
            | "GT" | "GE" | "EQ" | "NE" | "LE" | "LT" ;

Newlines matter in four places: P2, the header line, each // line and an EXECUTE body. Elsewhere whitespace is layout. Words are case-insensitive.

Constructs

Header and comment

NETWORK LABEL: Done DISABLED TITLE: "Fill the tank"
  // the comment, one or more lines
  lamp := a;
END_NETWORK

Coils

lamp := a;
lamp := motor := start;
x S= a;
x R= ;
NOT lamp := a;
R_EDGE lamp := a;

Several coils share one value. A modifier stands before its coil; an empty value is the rail.

Operator boxes

x := a ADD b;
x := a ADD b ADD c;
x := (a AND b) OR c;
lamp := a GT 40;

One word is one box with as many inputs as operands; a second word kind needs brackets.

MOVE

MOVE b => a;
MOVE b => a => c;
a := MOVE b;

EN

MOVE b => a EN c;
t1(IN := a, PT := T#1S) EN c;
x ADD 1 => x EN;
MOVE 5 => y NOT EN c;

EN follows the box; bare EN is the enable shown with nothing wired. An enabled box is the root of its line: its value leaves through => or its ENO.

ENO

MOVE 1 => a EN start
MOVE 2 => b EN ENO
done := ENO;

MOVE 1 => a EN c
MOVE 2 => b EN d
x := ENO AND ENO;

Each ENO takes the oldest open line above it (P3): the first is a chain, the second one box with two ENOs.

Splits

split1 := start AND auto;
motor := split1;
lamp := split1 AND NOT fault;

The split's number is the vendor's VarId. It may be defined nested (x := (split1 := a);) and needs no declaration or type.

BRANCH

lamp := start BRANCH (a, b AND c);
lamp := start BRANCH (a, b) SHORTCIRCUIT;
lamp := BRANCH (a, b);
lamp := start BRANCH (a, , b);
x := a AND (s BRANCH (b, c));

The drawn parallel. With no feed it starts at the rail; an empty branch is nothing between two commas.

Word or call

x := MUL(, a, 6);
x := AND(a, NOT IN2 := b);
MOVE(IN := , => x);
MOVE(0, ENO => lamp) EN c;
x := NOT(IN := a);

An empty slot, a pin modifier or a named output pin needs the call form.

Calls

t1(IN := a, PT := T#1S, Q => done);
`timers[1]`(IN := a, PT := T#1S);
y := LIMIT(0, v, 100);
y := f(a, err => e);
x := fb(xEnable := a).busy;

An FB's type comes from its instance's declaration.

Unnamed instances

??? : TON(IN := a, PT := T#1S);
t1(IN := ???, PT := T#1S);

??? is the vendor's own marker for an unfilled slot.

Empty slots

ctu(CU := a, RESET := , PV := 10);
lamp := ;
lamp := NOT ;
;

NOT and edges

lamp := NOT a;
lamp := NOT (a AND b);
up := R_EDGE(clk);
down := F_EDGE(NOT a);
t1(NOT IN := a, PT := T#1S);

LABEL, JMP and RETURN

NETWORK
  JMP Done := a AND b;
END_NETWORK
NETWORK
  RETURN := NOT ready;
END_NETWORK
NETWORK LABEL: Done
  JMP Start;
END_NETWORK

EXECUTE

EXECUTE EN go
i := i + 1;
  END_EXECUTE
done := ENO;

The ST lines are verbatim; the box is an open line like any enabled box.

Backticked operands

t1(IN := a, PT := `INT_TO_TIME(n)`);

Operand text that is not one token stays one operand, verbatim.

Members the text does not spell

y := f(a);       // pushed
y := f(i := a);  // pulled: the input name comes from f's declaration

A member the text does not show is derived on push from the text and the declarations, or is an editor cache that runs the same whatever it holds. An unchanged network is never rebuilt and keeps every member. A rebuild that drops a stored value is named by the push (RebuildLoss).

The body line

Every body states its language: IMPLEMENTATION ST, LD or FBD, and that line alone picks the reader. An abstract member with no code is IMPLEMENTATION NONE. A body Volt cannot show is IMPLEMENTATION <LANG> UNSUPPORTED with nothing under it: its declaration stays editable and a push never writes the body. CFC, SFC and IL are always shown this way.

A network that cannot be spelled

NETWORK TITLE: "Calc"
  UNSUPPORTED "a flag on a box input pin";
END_NETWORK

Pull never fails. A network holding a shape the text cannot spell keeps its header and comment and shows this one line. Pushed back unchanged, it is kept exactly as the IDE holds it. Edited, or in a new network, it is refused.

Pushing

A push pairs networks by their text, never by position (NetworkPairing). An equal network is not touched, a changed header is rewritten in place, changed items are rebuilt, and inserts and deletes touch no other network. Any layout that reads to a model is accepted; the next pull shows the writer's canonical layout, and the CLI brings the working tree to it.

The shared case set

test/fixtures/network-text/ holds accept/*.cases (a text and its model) and refuse/*.cases (a text and its error). The bridge's NetworkTextCaseTests and the LSP's network-cases.test.ts read the same files, so the editor refuses what a push refuses.

Errors

coderaised for
NETWORK_PARSEStructure: a missing ;, a body line with no LD or FBD, header fields out of order, a // after a statement, an unclosed backtick, title or EXECUTE.
NETWORK_NOT_CLOSEDA NETWORK with no END_NETWORK.
NETWORK_DUPLICATE_NAMEA split defined twice in one network.
NETWORK_BAD_EXPRESSIONA text that breaks a rule above: a redundant bracket, two word kinds on one level, an enabled box used as a value, an ENO with no open line or an open line nothing takes, the call form where the word fits, an undefined split.
NETWORK_UNKNOWN_OPERATORA symbol that is no box word; ST's + - * / and comparisons name the word to write.
NETWORK_UNSUPPORTEDA model the vendor cannot store or build, named by network and shape; an edited UNSUPPORTED line.

The language server

The LSP's network parser (volt-lsp-iec/src/frontend/syntax/network/) gives the same error at the same token as the push. Hover on ENO shows the line it takes, on BRANCH its branches, and on a split its feeder and references.
