Network text

An LD or FBD body is the stored network tree written as ST calls: every node is one call with its parts inside (), and the flow is each call's return. Lines starting with % carry what is not code. 

%LANGUAGE LD
%NETWORK "Start the motor"
VAR w1 : ANY; END_VAR
// runs while auto is on
w1 := start AND INVERT(stop);
ASSIGN(w1, Q => motor);
ASSIGN(MOVE(EN := w1, 100, OUT => speed), Q => lamp);

EN, ENO and outputs

A box hands on ENO where EN is shown; otherwise a function's value, an FB's or a program's first output. A dot names another output that flows on. A box whose flow nothing reads is a statement.

ASSIGN(GT(a, b), Q => x);
ASSIGN(GT(EN := c, a, b, OUT => v), Q => y);
ASSIGN(t1(EN := c, IN := a, PT := T#1S), Q => y);
ASSIGN(t1(IN := a, PT := T#1S).ET, Q => t);
ASSIGN(g(a, OUT => v).Q, Q => q);
GT(EN := go, i, j, OUT => v);
GT(EN := go, i, j);

Wires

A value read twice is a wire: declared : ANY on the network's VAR line, defined once, numbered w1, w2, … across the body in the order the text first names them.

%NETWORK
VAR w1 : ANY; END_VAR
w1 := a AND b;
ASSIGN(w1, Q => x);
ASSIGN(w1 AND c, Q => y);

Execute box

Its ST is its last pin, one string, ' written $' and $ written $$.

EXECUTE(EN := go, 'IF start THEN
    count := count + 1;
END_IF');
ASSIGN(EXECUTE(EN := go, 'msg := $'done$';'), Q => ok);
EXECUTE('n := 0;');

Reserved names

A POU or variable named INVERT, RISING, FALLING or ASSIGN is refused. So is a marked output name on a box that declares both Q and Q_SET (likewise _RESET, _INVERTED).
