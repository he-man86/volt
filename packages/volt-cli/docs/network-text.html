Network text

An LD or FBD body is ST: every box is a call, a contact is AND, OR or NOT between operands, a coil is an assignment. Lines starting with % carry what is not code. 

%LANGUAGE LD
%NETWORK "Start the motor"
%WIRES w1
// runs while auto is on
w1 := start AND NOT stop;
motor := w1;
lamp := MOVE_EN(EN := w1, 100, OUT => speed);

Wires

%NETWORK
%WIRES w1
w1 := a AND b;
x := w1;
y := w1 AND c;

A value read twice is a wire, defined once (w1 := … or Q => w1). A box read once stands where it is read.

What a network holds

Assignments, calls, jumps and returns. Any other ST stands only in an Execute box.

A network that cannot be spelled

%NETWORK "Calc"
%UNSUPPORTED "a coil modifier on a jump" #929f3675

Pushed back unchanged it stays as the IDE holds it; edited, the push is refused.

Pushing

A push rebuilds only the networks whose text changed; what the text does not carry is derived from the declarations or kept from the stored network.
