Volt ships two front ends over the same core: a **desktop app** and an **editor extension**. Same sync, same
language server, same workspace — they differ in whether you also get an editor around it. Both come in the one
installer, so this is a preference, not a purchase.

## The short answer

| | Desktop app | Editor extension |
| --- | --- | --- |
| Setup | Install and go | A few minutes — install the extension |
| Editor | None — it syncs, reports and diagnoses | VS Code, Cursor or Windsurf |
| AI agent | Not here — use any agent on the same folder | Your editor's own, plus `volt` in its terminal |
| IDE sync | The whole window | Volt views in the sidebar |
| Git | Pull / push / build buttons | Your usual Source Control view |
| Diffs | A popup per changed object | Native side-by-side, plus the merge editor |
| Best for | Watching and driving sync, on a panel machine | Actually writing the code |

**Not sure?** Run both. They share one workspace, so this is not a fork in the road — a common split is the
desktop app on the machine next to the panel, and your editor at your desk.

## The desktop app

One window: IDE Connection, IDE Sync and Diagnostics for your project. Nothing to configure, no extensions to
pick, no terminal required. It opens from the Start Menu or the Connector's tray icon.

**Choose it when**

- You want the fastest path from installer to a synced project.
- Your day is mostly CODESYS or TwinCAT, and the text side is new territory.
- You'd rather click **Pull** / **Push** / **Build** than remember git commands.
- You're evaluating Volt and want to see what it does without setting anything up.

**What you give up** — there is no editor here and no agent: it syncs, reports and diagnoses. Editing the code
and talking to an AI about it happen in your editor or agent, on the same workspace folder.

## The VS Code extension

The same PLC intelligence inside the editor you already have. Volt adds three views — IDE Connection, IDE Sync,
Diagnostics, the same three the desktop app shows — plus Structured Text language support and drift coloring,
which shows at a glance which files the IDE changed versus which ones you changed. It runs the same in VS Code,
Cursor and Windsurf.

<Figure wide caption="The VS Code extension — Explorer, Source Control and Volt's views side by side, with an agent in the integrated terminal.">
  <VSCode autoplay zoom={0.92} />
</Figure>

**Choose it when**

- You already work in VS Code, Cursor or Windsurf and want PLC code to behave like the rest of your code.
- You want your editor's own AI agent to see the project, with language intelligence and the `volt` CLI.
- You want your own extensions, keybindings, themes and tasks.
- You run git from the editor or the terminal and want Volt to stay out of the way.
- Your repo holds more than the PLC project — docs, scripts, CI, a second project.

**What it costs** — a few minutes of setup: install VS Code, let the Volt installer add the extension, open the
project folder, and connect from the Volt view.

## Using both

They share one workspace: the same git repo, the same binding to your live IDE. Pull in one and the other sees it.
A common split is the desktop app on the machine next to the panel, and VS Code at your desk.

The one rule: **don't push from both at the same time**. Push writes to the live IDE, and two writers racing each
other is exactly the mess git is supposed to prevent.
